# Repository workflow

- Commit completed, tested Exchange Walker changes to this repository.
- This repository is public. Never commit account profiles, credentials, raw
  live transcripts, or private shared-API implementation files.
- Keep independent installation with F2CE-Tools supported. Verify both the
  standalone adapter and optional shared API when shared source is available.
- F2CE-Tools source changes go to `ralphcma/f2ce-tools`, the user's fork, not
  directly to `federation2-community/f2ce-tools`.
- No force-push, release publication, live deployment, or gameplay without
  task-specific authorization. Preserve default OFF and explicit apply/start.
